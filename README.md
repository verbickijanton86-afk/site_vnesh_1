# auvix

## Ручное редактирование

Откройте [инструкцию «Как менять сайт»](EDITING.md): там указано, где править тексты, цвета, банки, мобильную версию и карусель.
Исходники разбиты на строки с отступами, а основные разделы подписаны русскими комментариями.

Адаптивный сайт партнёрской платформы AUVIX в глянцевой чёрно-белой палитре.

## Загрузка в GitHub

Откройте нужный репозиторий → **Add file → Upload files**. Загрузите содержимое этой папки в корень репозитория и нажмите **Commit changes**. Файл `index.html` должен находиться в корне.

## Cloudflare Pages через GitHub

Подключите репозиторий в Cloudflare Pages. Для этого статического сайта сборка не требуется: выберите **None**, оставьте команду сборки пустой и укажите каталог публикации `.`. Корень проекта — корень репозитория. Если файлы загружены вложенной папкой `flow`, укажите её как корень проекта.

## Локальный просмотр

В папке сайта запустите:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Файлы

- `index.html` — структура и тексты страницы.
- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — поиск, фильтры, калькулятор и демо-кабинет.
- `config.js` — банки, категории и ссылки.
- `favicon.svg` — иконка сайта.

Для подключения реальных предложений заполните `referralUrl` в `config.js` и согласуйте тексты с условиями банков. Сейчас каталог демонстрационный; банковские интеграции и выплаты не подключены. Демо-профиль сохраняется только в браузере посетителя. Шрифт Manrope загружается из Google Fonts, резервный шрифт — Arial.

## Главная / коллекция AUVIX

- На компьютере: перекрывающиеся карточки с вкладками. При наведении или фокусе выбранная карточка выходит вперёд, остальные затемняются.
- На телефоне: карусель с частично видимыми соседними картхолдерами. Поддерживаются свайп, перетаскивание, стрелки и индикаторы.
- С клавиатуры: Tab для выбора элементов, стрелки влево/вправо внутри карусели.
- При системной настройке уменьшения движения анимации отключены.
- Вся палитра сайта, включая банковские карточки и калькулятор, ахроматическая.

`assets/auvix-wordmark.svg` — векторный логотип. `assets/holder-initiate.jpg`, `holder-partner.jpg`, `holder-apex.jpg` — изображения картхолдеров INITIATE, PARTNER и APEX. Краткий промпт: три вертикальных картхолдера AUVIX (полированный серебряный металл, чёрная кожа, чёрный мрамор), равномерно расположенные на чёрном отражающем фоне; белый контровой свет, только чёрный, белый и серебристый, без интерфейса.

## Отправка анкет в Telegram

Анкета уходит на адрес `/api/application`, его обрабатывает `worker.js` и пересылает данные в Telegram.
Токен бота хранится только в секретах Cloudflare, в коде сайта его нет.

1. В Telegram откройте @BotFather, отправьте `/newbot` и получите токен.
2. Получатель открывает бота и нажимает **Start** (иначе бот не сможет ему писать).
3. ID получателя можно узнать у бота @userinfobot. Для нескольких получателей перечислите ID через запятую.
4. В Cloudflare: Workers & Pages → ваш проект → Settings → Variables and Secrets. Добавьте `TELEGRAM_BOT_TOKEN` (тип Secret) и `TELEGRAM_CHAT_ID`.
5. Загрузите проект заново (Deploy).
